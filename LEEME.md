## Desarrolladora Web · Desarrolladora Full-Stack · Diseñadora UI & Web

Soy desarrolladora web enfocada en crear experiencias digitales **funcionales, confiables y visualmente atractivas**.

Cuento con más de **4 años de experiencia** desarrollando sitios web y aplicaciones, combinando programación, gestión de bases de datos, diseño de interfaces y herramientas orientadas a negocios para crear soluciones que no solo sean técnicamente sólidas, sino también prácticas y fáciles de utilizar.
